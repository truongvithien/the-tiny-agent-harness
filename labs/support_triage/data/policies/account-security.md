# Account security

Synthetic policy text for the support-triage laboratory. It is not real advice.

## Locked accounts

An account locks after ten failed sign-in attempts and unlocks automatically
after thirty minutes. Never unlock an account on request alone.

## Password reset links

Send a password reset link only to the address already stored on the account.
Never read a password, a reset token, or a recovery code back to a customer.

## Address changes

A request to change the address on an account is handed to a human reviewer.
Support replies may not confirm such a change.
